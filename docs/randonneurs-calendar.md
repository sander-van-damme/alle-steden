# Sportagenda: Randonneurs België / Belgique

Source: [official calendar](https://randonneurs.be/kalender/) and [official Calendar API documentation](https://randonneurs.be/api/docs/), with [OpenAPI schema](https://randonneurs.be/api/v1/openapi.json). The publisher explicitly invites other websites to display the calendar through this public, free, read-only API. That permission is specific to the calendar feed; the publisher's general site footer reserves rights. We display only the event title and calendar facts (departure date/time/place, optional distance and registration deadline), with attribution and a link to the corresponding record. No images, route files, organizer prose, or account data are republished.

The browser sends a bounded date query to `https://randonneurs.be/api/v1/rides`, tagged `client=alle-steden`, with no credentials, visitor location or third-party registration links. Verified on 2026-11-24 with the production site as the request Origin: HTTP 200, JSON, `Access-Control-Allow-Origin: *`, `Cache-Control: public, max-age=900`, rate limit 500 requests per hour per IP. The adapter honors the 15-minute cache interval and treats a full 1,000-record response as potentially truncated. This is an additional, partial sports feed, not a general events inventory.

Only dated rides in known sports types are admitted. Cancelled records, already-started timed rides, undated permanent routes, the generic outings/social-event type, foreign Paris–Brest–Paris and uncertain city matches are omitted. Departure times and online deadlines use Europe/Brussels with the appropriate DST offset. A missing or ambiguous hour stays date-only. The source has a last calendar day for multi-day rides, but no finish hour; the sports calendar lists these on their departure date, not as all-day sightings or a visit window. Past online registration deadlines are distinct from event cancellation or full capacity; registration availability is otherwise not asserted. No sports ride becomes a sightseeing stop or itinerary option in the planner.

City matches use exact official catalog aliases, excluding homonyms and contradictory postal codes for guarded localities. A few additional start localities map to their city, checked against:
- [Gent: Oostakker and Zwijnaarde](https://stad.gent/en/expats-ghent/neighbourhoods);
- [Antwerpen: Ekeren](https://www.antwerpen.be/contact/loket-ekeren);
- [Oudenaarde: Mater](https://inspraak.oudenaarde.be/uploads/7d8b210e-c578-420b-83ba-c01e8ad4ccae/phase_file/file/20e5dca7-fbe1-4e2f-8c90-39a8c222d8f1/201217_Startnota_RUP_Linkeroever.pdf);
- [Tournai: villages including Mourcourt](https://www.tournai.be/services-communaux) and [local address 7543](https://associations.tournai.be/organizations/la-mourcourt-maison-de-village);
- [Oostende: Zandvoorde](https://www.oostende.be/beweeginjebuurt-zandvoorde), only with postal code 8400; another Zandvoorde shares the name;
- [bpost: postcode-to-locality verification](https://www.bpost.be/site/nl/docs/zipcodes/zipcode_alpha.html). For example, a publisher row named “Brussel” with postal code 1070 belongs to Anderlecht, not the catalog's City of Brussels.

Live audit with the actual city catalog on 2026-11-24: the official response lists 60 rows for 2026-11-24 through 2027-11-24 (57 BRM, 1 RM, 1 generic event, 1 foreign PBP). Of these, 33 Belgian rides had enough evidence to match to 16 catalog cities; through 2027-03-24, 7 rides matched in 5 cities. Examples: Brugge 2026-12-13 at 08:00, Antwerpen 2027-03-20 at 06:00, Gent’s two differently timed “Double Trouble” departures on 2027-05-01, and Marche-en-Famenne 2027-05-06 at 06:00. Unmatched rides are omitted rather than attributed to the nearest city.
